# Справжня 3D-змійка

Змійка в кубі 7³–15³ (за замовчуванням 13 × 13 × 13) на three.js (r128, `vendor/three.min.js`). Без збірки — відкрий `index.html` у браузері.

**Керування:** WASD / стрілки — горизонтально, E / Q — вгору / вниз, Space — пауза, R — заново, C — повернути камеру, L — таблиця рекордів, перетягування — обертання, коліщатко — масштаб.

Клавіші прив'язані до фізичних кнопок, тож працюють у будь-якій розкладці (англійська, українська тощо).

Натиск напрямку одразу робить крок: новий напрямок — миттєвий поворот, поточний — додатковий крок. Утримання клавіші поточного напрямку — прискорення (до ~3× швидше).

## Налаштування і рекорди

- Розмір поля (7, 9, 11, 13, 15) і складність обираються внизу; вибір запам'ятовується.
- Таблиця рекордів — топ-10 окремо для кожної пари «складність × розмір», зберігається в `localStorage` браузера. Відкривається кнопкою з кубком, клавішею L або з меню паузи / кінця гри.

## Оптимізації швидкодії

- Тіло змійки — один `InstancedMesh` замість окремого меша на кожен сегмент: draw calls не ростуть із довжиною (було `довжина + ~20`, стало 16 сталих).
- Сітка зайнятості `Uint8Array(N³)`: перевірка самоукусу O(1), пошук вільної клітинки без рядків і `Set`.
- Інтерполяція руху без копіювання всієї змійки щотіку (зберігається лише старий хвіст).
- Пул частинок: меші й матеріали створюються один раз.
- HUD: закешовані DOM-вузли, текст пишеться лише при зміні.
- Лінія-підказка до яблука оновлюється тільки при його переміщенні.
- Під меню (пауза / старт / кінець гри) з нерухомою камерою кадр не перемальовується.
- Прибрано `backdrop-filter` з HUD-бейджів над WebGL-полотном.
- Адаптивна роздільність: при стабільно повільних кадрах `pixelRatio` знижується (не нижче 1) і повертається, коли стає швидко.
